## 🖼️ 1. Editor & Design
- **Image Editor**: Layers, masks, brushes, text, filters, curves, levels.
- **Annotation Tool**: Arrows, shapes, highlights.
- **Freehand Drawing**: Custom brushes.
- **Sticker / Icon Overlay**: Add graphics to images.
- **Text-on-Image / Text-on-Path**: Advanced typography tools.
- **Image Collage Maker / Merger**: Combine multiple images.
- **Meme Generator**: Templates and custom captions.

## 🔄 2. Format Conversion
- **Standard Conversion**: JPG ⇄ PNG ⇄ WebP ⇄ AVIF.
- **Apple Formats**: HEIC → JPG / PNG.
- **Professional Formats**: TIFF → JPG / PNG, BMP → JPG / PNG.
- **Vector & Icons**: SVG → PNG / JPG, ICO / EPS → PNG.
- **Animations**: Image → GIF, GIF → JPG / Image Sequence.
- **Documents**: Image ⇄ PDF.
- **Batch Image Converter**: Any-to-any bulk processing.

## 📏 3. Resize, Crop & Transform
- **Image Resizer**: Pixels, percentage, aspect ratio (single & batch).
- **Image Cropper**: Manual, presets, and auto subject/face detection.
- **Batch Image Cropper**: Apply crop settings to multiple files.
- **Image Rotator / Flipper**: Quick orientation adjustments.
- **Image Straightener**: Auto horizon correction.
- **Perspective / Skew / Distort**: Advanced geometry tools.

## ⚡ 4. Compression & Optimization
- **Image Compressor**: Lossy/lossless options with target size limits.
- **Batch Image Compressor**: Bulk optimization.
- **Progressive JPEG Converter**: Optimize for web loading.
- **Web Optimization**: WebP/AVIF presets and responsive size generation.

## 🎨 5. Color & Adjustments
- **Color Adjuster**: Brightness, contrast, saturation, exposure, etc.
- **Filters**: Grayscale, Sepia, Invert.
- **Artistic Effects**: Posterize, Threshold, Solarize.
- **Color Profile Converter**: sRGB, CMYK profiles.
- **Histogram Equalization**: Automatic tonal balancing.

## 🤖 6. AI & Smart Tools
- **Background Remover**: Automatic AI-powered isolation.
- **Object Remover**: AI inpainting to remove unwanted elements.
- **Image Enhancer / Upscaler**: Super-resolution scaling.
- **Face Retouch**: Skin smoothing and blemish removal.
- **Background Blur**: AI-driven portrait mode.
- **Colorizer**: B&W to Color transformation.
- **Dehaze Tool**: Improve clarity in foggy or hazy photos.

## 🔍 7. Analysis & Utilities
- **Metadata Viewer**: EXIF, GPS, and camera data.
- **Metadata Editor / Remover**: Clean or modify image tags.
- **Format Identifier**: Deep file analysis.
- **Color Picker / Palette Extractor**: Extract hex codes from images.
- **Dominant Color Extractor**: Identify primary color schemes.
- **Image Comparison Tool**: Before/after slider interface.

## 🧾 8. Document Tools
- **Document Scanner**: Auto edge detection and perspective fixing.
- **OCR**: Image to Text extraction.
- **Signature Extractor**: Isolate signatures for digital use.

## 🎞️ 9. GIF & Animation
- **GIF Maker**: Convert images to animated GIFs.
- **GIF Editor**: Frame-by-frame management.
- **GIF Compressor**: Reduce file size of animations.
- **GIF Speed Changer**: Adjust playback velocity.
- **Video → GIF**: Convert video clips to high-quality GIFs.

## 🔐 10. Privacy & Security
- **Blur / Pixelate**: Manually hide sensitive information.
- **Face Blur**: Automatic face detection and blurring.
- **Metadata Stripper**: One-click privacy cleaning.

## 🏷️ 11. Branding & Content Tools
- **Watermarker**: Text or logo overlays (single & batch).
- **Image Border / Frame**: Add decorative borders.
- **Thumbnail Generator**: Bulk creation for galleries.
- **Social Media Presets**: One-click cropping for Instagram, X, etc.
- **Favicon Generator**: Create multi-size .ico and .png icons.

## 🔄 12. Batch & Automation
- **Batch Renamer**: Pattern-based renaming using metadata or sequences.
- **Workflow Automation**: Custom pipelines (e.g., Resize + Compress + Convert).

## 📦 13. Developer & Power Tools
- **Base64 Tool**: Encode/decode images to Base64 strings.
- **Image Sprite Generator**: Combine images for CSS sprites.
- **Responsive Image Generator**: Generate `srcset` variations.
- **QR Code Generator**: Create custom QR codes.
- **QR Code Scanner**: Read data from image-based QR codes.

## 📸 14. Capture
- **Screenshot Tool**: Full page, region, scrolling, and annotated captures.
