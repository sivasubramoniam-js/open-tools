# Open Tools

A curated collection of useful tools designed to simplify everyday tasks and improve productivity in daily life.

## 🚀 Features

- **Multi-Format Converters**: Seamlessly switch between Image, Video, Audio, and Document formats.
- **AI-Powered Utilities**: Local LLM and Whisper-based tools for transcription, summarization, and generation.
- **Privacy First**: Local encryption, secure shredding, and offline processing.
- **Developer Suite**: Formatters, validators, and regex testers for modern workflows.
- **Productivity Hub**: Task management, note-taking, and knowledge base builders.

- **Transform**: Resize (pixel/percentage), Crop (manual/auto-face), Rotate, Flip, and Mirror.

- **Editing**: Multi-track timeline, trim, merge, transitions, speed ramping, and keyframe animation.

- **Subtitles**: Local Whisper-based Auto-Captioning, Subtitle Extractor, and Burn-in tool.
